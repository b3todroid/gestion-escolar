# Gestión Escolar

PWA local-first para configurar una escuela (ciclos, turnos, jornadas, periodos, recesos, grados y grupos) desde el teléfono, sin conexión permanente.

**Windows:** doble clic en `iniciar.cmd` (instala lo necesario, inicia el servidor y abre el navegador; no cierres la ventana negra).

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # tipos + pruebas + compilación
npm run test:e2e # pruebas funcionales (Playwright)
```

Documentación en `docs/`; reglas para colaboradores (y Claude Code) en `CLAUDE.md`.
